# 小红书运营 Copilot

一个面向创作者的 AI 运营辅助产品 Demo。项目目标不是替用户自动发布内容，而是把模糊运营问题拆成可诊断、可确认、可复盘的流程。

## 项目定位

创作者常见问题不是“缺一段文案”，而是无法判断账号当前卡在哪一环：定位是否清晰、选题是否成立、标题和封面是否承接点击、正文结构是否支持完读、数据下滑应从哪里复盘。

小红书运营 Copilot 将这些问题拆成三条主路径：

- 冷启动诊断：账号定位、人设表达、内容支柱、前期选题。
- 日常内容生产：选题判断、标题 A/B、封面重点、正文结构。
- 效果复盘：曝光、点击、完读、互动、关注和转化漏斗。

## 展示边界

本仓库只放个人项目公开材料，不包含任何实习公司资料、真实客户信息、内部系统、后台数据或不可公开文档。

个人内容平台数据只作为场景理解来源，不写成 Copilot 的产品效果。
