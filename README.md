# 小红书运营 Copilot

一个面向创作者的 AI 运营辅助产品 Demo。项目目标不是替用户自动发布内容，而是把模糊运营问题拆成可诊断、可确认、可复盘的流程。

## 项目定位

创作者常见问题不是“不会发内容”，而是不知道自己当前处于什么内容阶段，因此不知道此刻该发什么、为何要发、发完后又该如何继续。

小红书运营 Copilot 先把内容运营组织成一个持续策略周期：

`阶段判断 -> 内容策略 -> 内容行动 -> 复盘回流`

原有任务仍保留为具体能力路径：

- 冷启动诊断：账号定位、人设表达、内容支柱、前期选题。
- 日常内容生产：选题判断、标题 A/B、封面重点、正文结构。
- 效果复盘：曝光、点击、完读、互动、关注和转化漏斗。

阶段判断提供四种可调整的当前策略建议：探索方向、验证内容模型、系列化运营、针对性优化。它们不是永久账号标签。

## 仓库内容

- `index.html`：公开 Demo 的页面入口。
- `app.css`：独立 Demo 的视觉与响应式样式。
- `app.js`：工作台、阶段判断、内容策略、行动卡与复盘回流的前端状态与交互。
- `docs/product-brief.md`：产品简报。
- `docs/workflow.md`：核心 Workflow。
- `docs/eval-and-badcase.md`：评测样例与 Badcase 处理。


## 体验路径

- 工作台：查看当前阶段、本轮策略、待完成行动与待回填复盘。
- 阶段判断：从当前困惑、已有内容与反馈中形成可调整的阶段建议。
- 内容策略：围绕同一个假设选择关联选题，而不是生成零散热点。
- 内容行动与复盘：保存本轮要验证的内容，并把观察回流为下一轮建议。

每条路径都经过“补充现状 → 查看判断 → 确认行动”。页面不会自动发布内容，也不会把示例建议包装为增长承诺。
