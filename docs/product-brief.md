# 产品简报

## 一句话定位

小红书运营 Copilot 是一个帮助创作者诊断运营卡点、生成下一步内容动作并沉淀复盘记录的 AI 产品 Demo。

## 目标用户

- 从 0 到 1 起号的新手创作者。
- 已经持续发布但数据不稳定的个人创作者。
- 希望把选题、标题、封面、正文、复盘形成流程的内容运营者。

## 核心问题

很多创作者把问题描述成“帮我写一篇笔记”“最近数据不好”，但真实卡点可能来自账号定位、选题价值、标题点击、封面承接、正文结构、互动反馈或复盘指标。

## P0 流程

1. 输入账号阶段、内容方向、近期数据或模糊问题。
2. Copilot 判断当前任务属于冷启动、内容生产还是效果复盘。
3. 系统输出问题判断、可能原因、建议动作和下一轮验证指标。
4. 用户确认信息是否准确，再决定是否生成选题卡、标题 A/B、封面建议或复盘表。

## 产品边界

- 不自动发布内容。
- 不编造后台数据。
- 不把单条爆款归因成固定公式。
- 缺少关键数据时先追问，不直接给确定结论。
