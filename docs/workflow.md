# Workflow

## 冷启动诊断

输入：账号方向、目标人群、个人优势、可持续内容资源。

输出：定位句、人设关键词、内容支柱、前 10 个选题方向。

关键判断：用户能否持续生产，账号表达是否垂直，内容是否有明确受众。

## 日常内容生产

输入：主题、目标读者、想表达的观点、素材、发布目标。

输出：选题卡、标题 A/B、封面重点、正文结构、互动引导。

关键判断：标题是否有搜索词，封面是否承接点击，正文是否支持完读和收藏。

## 效果复盘

输入：曝光、点击、完读、互动、关注、转化，以及用户自己的复盘描述。

输出：问题环节、可能原因、优化动作、下一条内容验证指标。

关键判断：不要只看单一数据，要按漏斗定位问题发生在哪一层。

## 内容诊断漏斗

曝光 -> 点击 -> 完读 -> 互动 -> 关注 -> 转化

每一层都对应不同产品动作：

- 曝光低：检查选题热度、关键词、发布时间和账号权重。
- 点击低：检查标题、封面、首屏利益点。
- 完读低：检查正文结构、信息密度和开头承诺。
- 互动低：检查观点锋利度、收藏价值和评论引导。
- 关注低：检查人设一致性和系列内容承接。
