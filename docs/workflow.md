# 产品流程

## 核心问题

Creator Copilot 面向已经会发布内容、但不确定“现在该发什么、为什么发、发完如何继续”的创作者。它不自动发布，也不把单条数据包装成增长承诺。

## 持续闭环

`诊断依据 -> 阶段建议 -> 选题规划 -> 内容行动队列 -> 选择已发布内容复盘 -> 判断记录 -> 推荐下一阶段`

每个环节只承担一个必要职责：

| 环节 | 用户的问题 | 输出 |
| --- | --- | --- |
| 阶段判断 | 我现在该先解决什么？ | 推荐阶段、三条判断依据、用户可修改的策略建议 |
| 选题规划 | 这一轮具体发什么？ | 与阶段相符、且有明确验证目的的三条选题 |
| 内容行动队列 | 我目前有哪些内容在推进？ | 多条独立行动及其待撰写、等待观察、已复盘状态；每条保留最小内容简报 |
| 单条复盘 | 这次数据属于哪条内容、说明什么？ | 与被选行动绑定的信号、理解、调整和下一轮验证；并和同类内容基准、本轮观察目标对照 |
| 下一轮建议 | 我应该继续、调整还是换一种做法？ | 非线性的下一阶段推荐，用户可以采用或自行调整 |

## 阶段建议

阶段不是固定流水线，也不是永久标签：

- 找到方向：内容或反馈不足，先比较读者真正关心的问题。
- 确认有效内容：已有线索，但需要验证哪种表达值得持续。
- 做成内容系列：同类内容持续出现正向信号，补齐读者路径。
- 针对性调整：主题可保留，但问题集中在一个表达环节。

复盘会根据行动的阶段、用户选择的结果状态和观察信号推荐下一阶段：

- 信号不足：继续探索或继续验证；
- 信号清晰：从探索进入验证，或从验证进入系列；
- 问题集中：进入单变量优化；
- 系列仍有需求：继续补齐系列。

推荐不强制跳转，用户始终可以回到阶段判断修改。

## 热点素材池

输入：用户添加的公开链接、活动候选或公开讨论。

每条素材显示：

- 来源与添加时间；
- 可借用的内容角度；
- 对当前本轮问题的帮助；
- 暂不采用的情况。

热点只是一种外部素材。当前版本不宣称解析链接内容、获取实时平台热度或自动发布。

## 最小内容简报

保存内容行动时，用户补齐四项足以让一次决策落地的信息：

- 写给谁；
- 想让读者记住的一句话；
- 开头的真实场景；
- 需要准备的素材。

它不代替笔记正文，也不把创作变成复杂表单；目的只是让“这条要发什么”能够被执行和复盘。

## 复盘参照

复盘不只展示单独的数据。它同时呈现近期同类内容的基准与本轮观察目标：收藏、追问等目标有不同的比较方式；“读者是否看懂场景”则明确标为需要结合评论判断，不能被数据直接证明。
